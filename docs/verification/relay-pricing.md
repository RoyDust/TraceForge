用户指定 deepseek-v4.1-flash，现有中转仅返回 CLI Proxy API Server 与 chat/completions、completions、models 三个模型接口，没有可确认的公开计价页。公开检索未找到该中转的费率表；不能据此认定它免费或按官方价收费。

官方一手来源：https://api-docs.deepseek.com/quick_start/pricing （本轮联网读取）。该页对 DeepSeek-V4.1-Flash 使用 deepseek-flash 模型名，列出以下 USD / 百万 Token 费率：

| 项目 | 高峰 | 低峰 |
| --- | ---: | ---: |
| 输入，缓存命中 | 0.006 | 0.003 |
| 输入，缓存未命中 | 0.30 | 0.15 |
| 输出 | 1.20 | 0.60 |

官方高峰为周一至周五 UTC 01:00–04:00、06:00–10:00，中国公共假日除外，其余为低峰。以上仅为检索时的官方参考信息，不是第三方中转的账单承诺。

当前 ModelPricing 只表达固定输入/输出单价和生效时间，无法完整表达缓存与峰谷规则。中转可能有加价、折扣或不同结算币种。没有中转后台费率/账单前，不写入伪精确的 ModelPricing；实际 Token、延迟和链路仍正常记录，成本保持未知。

后续需要：中转明确的币种、每百万输入/输出 Token 的实际单价与生效时间；如区分缓存/高低峰，需另外确认计费规则再扩展，不以官方参考值代替。
